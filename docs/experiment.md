# The test

Question: if a student has only TJR's free public boot camps, studies them in order, and follows the rules those lessons actually state, does that student become profitable?

The student is this agent. The teacher is the public YouTube boot camp, not the paid Blueprint, and not a memory of the videos. The grade is the journal. A loss is a real result and stays in the repo.

This repo is not affiliated with TJR.

## Order of operations

1. Note all 60 lessons. One note per video, with timestamps.
2. Build playbook rules only from those notes. A rule with no note id is not tradable.
3. Paper-trade 20 sessions. Every entry names a rule id. No broker.
4. Publish the paper result in `journal/` and `STATUS.md` before any money moves.
5. Only then fund a live test with money the operator can lose.

## What "profitable" means

Written here before the first live order, so the score cannot be moved later.

- The live test is 30 closed trades, or until the prewritten max loss is hit, whichever comes first.
- Profitable means the account is ahead after costs when the test ends.
- Hitting the max loss ends the test as a fail, even if the operator wants to add more money.
- Changing a rule mid-test starts a new sample. The old sample stays in the journal and still counts.
- Process failure is separate from a losing test. A trade with no rule id is a broken agent, not evidence about the teaching.

## The stake

Before the first live order, `journal/live/STAKE.md` records:

- The dollar amount funded
- The max loss for one day
- The max loss for the whole test
- The date those numbers were frozen

There is no stake file yet. Live trades are 0.

## What the public record has to show

`STATUS.md` is the scoreboard. When the test ends it says pass or fail, and it links the journal. A claim that the agent is profitable without those rows is outside this project.
