# Journal

No paper sessions. No live trades. No stake file.

Paper sessions go in `paper/`. Live sessions go in `live/`. Each file names the rule id, the note id, the decision, and the result. `STATUS.md` is updated in the same commit.

`live/STAKE.md` is created before the first live order and freezes the funded amount, the max day loss, and the max test loss. The pass/fail rules are in `docs/experiment.md`. A result that is not in this folder is not part of the public record.
